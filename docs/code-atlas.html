Lab 2: StreamCell Monotonic Word-Wrap & Split-ANSI Escape Sanitizer

          

            StreamCell solves two subtle streaming problems in simple_agent/tui/rendering.py:
            (1) committing word-wrapped rows as soon as later tokens can no longer reflow them, and
            (2) buffering incomplete trailing \x1b[... escape prefixes across chunk boundaries so untrusted
            model or file text can never inject terminal control codes.

            Why rows[:-1] is safe to commit immediately:

            In wrap(text, width) (rendering.py:84-113), once a word overflows the current row and starts a new row,
            appending characters to that new word can only grow or split the last row—it can never pull characters back onto earlier rows.
            self.committed records how many wrapped rows of self.line have already been emitted!
